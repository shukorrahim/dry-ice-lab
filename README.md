# Makmal Ais Kering / Dry Ice Lab

Interactive bilingual (BM/EN) station for a school science fair, built around four dry ice experiments:

1. Hot vs cold water: which makes more fog?
2. Coloured water: is the fog coloured? (plus a universal indicator twist)
3. Candles next to dry ice: lit or out?
4. Dry ice balloon: how many litres of CO₂ gas?

Each experiment has a class prediction vote, a live simulation, the answer and explanation, and steps to run it for real. A safety tab covers handling rules.

Open `index.html` in any browser, or use the GitHub Pages link.
